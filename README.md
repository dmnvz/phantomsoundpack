# Daruma Audio — библиотека звуков

Звуковые эффекты студии [Daruma Audio](https://daruma.audio). Каждый пак — своя папка.

| Папка | Что внутри | Звуков |
|---|---|---|
| `PHANTOM/` | Phantom Sound Pack: клики, вжухи, сигналы, появления | 50 |
| `DARUMA VOL. 01/` | Звуки интерфейсов, вжухи, бумага, письмо, клавиатура, монеты, часы, колокольчики | 537 |

Все файлы — WAV, 48 кГц, 24 бит, стерео.

## Описания и теги

В каждой папке пака лежит `metadata.csv`:

- `file` — путь к файлу внутри папки пака;
- `name` — название звука;
- `description` — описание словами через запятую (из него берутся теги и поиск на сайте);
- `category`, `subcategory` — папки, в которых лежит звук;
- `duration_s` — длительность в секундах.

`DARUMA VOL. 01/DA SFX VOL 01.xlsx` — исходная таблица описаний.

## Как добавить звуки

1. Положить файлы в папку пака (или создать новую папку для нового пака). Имена — латиницей, без пробелов: `DA_WHOOSH_FAST_21.wav`.
2. Дописать строки в `metadata.csv` этого пака.
3. Отправить:

```bash
git add .
git commit -m "Новые звуки"
git push
```
